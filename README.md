# DASH Portfolio Dashboard

DASH is a mobile-friendly personal portfolio, market, news, and intelligence dashboard.

## What I am building

The goal is to create one dashboard that can eventually work on:

- Laptop
- Desktop
- Tablet
- Phone

The project will be built gradually while I learn GitHub, web development, APIs, data visualization, automation, and deployment.

## Planned Features

### Portfolio
- Holdings
- Average cost
- Current value
- Profit/loss
- Portfolio allocation
- Dividend income

### Markets
- S&P 500
- Nasdaq
- Dow Jones
- TSX
- Gold
- Oil
- Bitcoin
- USD/CAD

### Watchlist
- Stock watchlist
- Price movements
- Market news
- Alerts

### Intelligence
- Financial news
- Technology news
- Canadian news
- Geopolitical developments
- AI-generated summaries

### Mobile
- Responsive interface
- Progressive Web App
- Add-to-home-screen support
